# nitpickr website: design rules

The token sheet for `website/` (the marketing site and docs, published from `dist/site`) and for
`design/nitpickr-website.pen`. The front matter is generated from what the pages render: run
`design/tools/pen-baseline/capture.mjs` against a local build, then `sync.sh`, and never hand-edit a value.
Code wins ties: `website/styles.css` is the source of truth.

## What the code defines

- Custom properties on `:root` in `website/styles.css`: `--bg`, `--bg-soft`, `--surface`, `--surface-strong`,
  `--line`, `--line-strong`, `--text`, `--text-soft`, `--text-muted`, `--accent`, `--accent-deep`,
  `--accent-soft`, `--shadow`, `--radius-sm/md/lg` (18/28/40 px), `--container`, `--narrow`, `--header-height`.
- Type: Space Grotesk for display headings, IBM Plex Sans for body, IBM Plex Mono for eyebrows, labels and code,
  all self-hosted (`website/assets/fonts`, same families as Google Fonts, which Pen uses).
- Sizes are `rem`/`clamp()`, so font sizes and spacing are fluid: the scales above are the pixel values the
  pages render at 1440 and 390 px wide, not a designed scale.

## Principles (read from the CSS)

- Warm paper ground (`bg` #F6F1E8 with soft radial washes), ink text, one burnt-orange accent for the primary
  action and the eyebrows.
- Translucent white cards (`surface`, `surface-strong`) with hairline `line` borders and one soft shadow
  (`elevation.shadow1`, the `--shadow` property).
- Pill buttons and nav (`rounded-full`), large card radii (`rounded-md` 28 px).
- Light only: `styles.css` has no dark scheme.

## Open questions

- 20 `literal-*` colours have no custom property: mostly `--text`'s ink (#1F1913) at 3–18% alpha for rules and
  table stripes, white at several alphas for glass, and the page-background gradient stops. Should they become
  properties (`--line-faint`, `--glass`…) so the site and the Pen file share names?
- Spacing and type have no scale: 54 spacing values and 26 font sizes come from `rem` maths and `clamp()`. A
  4/8 px spacing scale and a fixed type ramp would make the design file much smaller.
- Values marked "from layout" are gaps made of margins (no gap property); they bind but aren't design decisions.
- `--accent-soft` is defined but nothing renders it.
- `hq design tokens-check nitpickr` can't read plain custom properties yet (pixeldog-studio/hq#156).

## Anti-defaults (avoid in every design)

- Purple/blue SaaS gradients, glassmorphism stacks, neon.
- More than one accent colour; accent used for decoration rather than action.
- Dense feature grids of identical cards with icons.
